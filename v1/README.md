# 肥肥财经 · v0.3 本地体验版

此版可以当作每天留在桌面上的第一版来用：小猪能拖动、记住位置，点空白处会穿透，开着的时候会在 12:00 和 20:30 各提醒一次。简报里的句子来自已经打开并逐字核对过的原文，指数来自交易所快照。打不开正文的内容不会被写进来。

**交给 Cursor 继续时，请先阅读 [CURSOR_HANDOFF.md](CURSOR_HANDOFF.md)。** 里面列有文件地图、已检查项、已知问题和建议开发顺序。

## 体验方式

- **网页**：直接打开 `index.html`，或在项目目录运行 `python3 -m http.server 8765 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8765`。
- **Mac 桌宠**：打开 `dist/肥肥财经.app`。点击小猪打开卡片，拖动调整位置；菜单栏“肥肥”可以换表情、打开网页、隐藏、恢复位置和退出。
- **网页桌宠模式**：点击“进入桌宠模式”，再点击或拖动小猪。可切换三种表情、午间/晚间简报和设置。

Mac 体验包为当前机器架构的本地构建，使用临时本地签名；尚未进行公开分发所需的开发者签名与公证，也未构建 Windows 版本。

## 开发

网页为原生 HTML/CSS/JavaScript，无依赖、无构建步骤。Mac 外壳使用 Swift + WebKit，通过 `zsh scripts/build-macos.sh` 重新打包，需安装 Apple 命令行工具。

更新简报：

```sh
python3 scripts/fetch-brief.py
```

脚本只用系统 `curl` 打开白名单里的原文和交易所接口。一句话必须能在正文里原样找到，指数的现价、涨跌额、涨跌幅必须互相算得上，才会写入 `data/brief.js`。20:30 之前只发布午间，不会把同一份内容标成晚间复盘。网页刷新即可；Mac 桌宠需要重新打包后再打开。

- `assets/reference/`：用户原始参考图。
- `assets/pig/`：三种透明背景小猪初版 PNG，使用内置图像工具抠图；边缘仍可进一步精修。
- `native/PigPet.swift`：透明窗口、菜单栏与网页桥接。
- `PRD.md`：产品需求，含来源核验与原始链接规则。

图像处理提示词和原始素材的对应关系见 `assets/pig/制作记录.md`。

## 来源说明

每条新闻都有发布机构、原文时间和一条能打开的具体链接。页面上的句子就是原文里的那一句，外文不翻译。指数写着快照时间，15:00 前明确不是收盘价，打开页面后也不会自己跳动。“已与原文核对”只表示这句话和所链页面一致。公司公告 PDF 在读出正文之前不会列入。
